# Музыкальный справочник

Нижняя панель: Лента, Мои группы, Поиск, Сохранено. Области нажатия не меньше 44 CSS px; учитываются safe area Telegram и уменьшение движения. Цвета прежние. Поиск запускается по кнопке, а не на каждый введённый символ. Результаты музыкального поиска Wikidata выбираются вручную, чтобы не склеивать одноимённых исполнителей.

Справка: Википедия, Wikidata, имеющиеся официальные сайты. Это источники с указанием происхождения, а не голосование сайтов за «истину». Википедия и Wikidata связаны и не считаются независимыми подтверждениями. Официальный опубликованный состав сохраняет приоритет для нынешних участников. Отсутствие даты окончания в Wikidata не превращается в «по настоящее время». Роли музыканта вообще не подставляются как подтверждённая роль в конкретной группе. Неполные даты не используются для точного возраста. Для умерших указан возраст на момент смерти.

Периоды участия, включая несколько возвращений, извлекаются из раздела состава Википедии. Бывшие и записи с неопределённым статусом показаны отдельно. В альбоме трек-лист и кредиты взяты из соответствующих разделов страницы альбома. Состав группы не подставляется вместо участников записи. Каталог Wikidata может включать студийные и концертные альбомы и быть неполным. Альбомы музыканта по прямому кредиту не выдают все альбомы его групп за его личную дискографию.

Живой поиск и справка обращаются к публичным API Wikidata, Wikipedia и Wikidata Query Service с ограничением частоты, тайм-аутом и защитой от устаревших ответов поиска. Некоторые провайдеры и WebView могут ограничить запросы. При ошибке есть повтор, существующая новостная лента продолжает работать. Небольшой публичный кэш для Dream Theater, Deep Purple, Opeth и Wolves in the Throne Room обновляется отдельным недельным workflow. Данные старше семи дней читаются из API заново.

Сетлисты: `refresh_setlists.py` использует секрет репозитория `SETLIST_FM_API_KEY`. В клиенте ключа нет. Ключ нужно получить у setlist.fm; до этого интерфейс прямо сообщает, что автоматическое подключение отсутствует. `setlist_review.json` содержит проверенные исполнители и идентификаторы полных сольных концертов со ссылкой, подтверждающей формат. Неизвестный формат не считается сольным, фестивали и неполные сетлисты не участвуют в анализе. Сравниваются не более десяти проверенных концертов одного тура. «На всех концертах выборки» не означает обязательную песню будущего концерта. Различие частот показывает изменяемые песни, но не утверждает, что песни заменяют друг друга в конкретной позиции. У API есть лицензионные ограничения на коммерческое использование.

Избранное и скрытые исполнители хранятся на устройстве. Скрывается вся статья, если в ней обнаружен скрытый исполнитель, в том числе в ленте избранного и сохранённых. При добавлении в избранное скрытие снимается. Эти настройки НЕ синхронизируются с Telegram-ботом. GitHub Pages не может безопасно хранить токен бота или обслуживать персональные настройки подписчиков: для этого нужен сервер с проверкой Telegram initData. Это отдельная архитектурная задача, а не обещанная возможность текущей версии.
